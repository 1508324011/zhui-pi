# Bidirectional Alignment Templates

## Minimal Alignment

```text
Goal intent: I understand that you want to ...
Expected result: The final output should be ...
Action: I will ...
Boundary: I will not ...
Please correct this before I proceed if any part is wrong.
```

## Ambiguous Request

```text
I should align before acting because this could be interpreted in multiple ways.

Goal intent options:
1. ...
2. ...

Expected result options:
1. ...
2. ...

Which interpretation is closer?
```

## AI Guidance For A Beginner

```text
Before asking AI to produce an answer, clarify:
- Why am I doing this?
- What decision or action should the output support?
- What should the final artifact look like?
- What should the AI avoid assuming?
- What would make the output unusable?
```

## Product Work Alignment

```text
Goal intent:
Who needs this, what problem are we trying to solve, and why now?

Expected result:
Do we need a clarified requirement, a PRD, a task breakdown, a review comment, or a decision memo?

Boundary:
What is outside this pass, and what is still unknown?
```
